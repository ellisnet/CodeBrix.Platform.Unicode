THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Platform.Unicode is a CodeBrix-family redistribution of the
International Components for Unicode (ICU) 77 native binaries for Windows
and macOS, packaged as two .NET 10 NuGet libraries from this one
repository (CodeBrix.Platform.Unicode.ApacheLicenseForever for Windows;
CodeBrix.Platform.UnicodeMacOs.ApacheLicenseForever for macOS). The
packages incorporate third-party material from two distinct sources:

  1. Uno.icu-win 77.2.1 and Uno.icu-macos 77.2.1 (Apache-2.0) — the
     original packaging shape, `.targets` MSBuild logic for embedding the
     ICU data archive, and the specific bundling of pre-built ICU 77
     binaries for win-x64 + win-arm64 (icu-win) and universal macOS
     (icu-macos). Upstream copyright: Copyright (C) 2015-2025
     Uno Platform Inc.
  2. ICU 77 (Unicode-3.0) — the actual native binaries (`icuuc77.dll`,
     `icudt77.dll`, `libicuuc.dylib`, `libicudata.dylib`) and the data
     archive (`icudt.dat`), built from the upstream ICU project at
     https://github.com/unicode-org/icu.
     Upstream copyright: Copyright (c) 2016-2025 Unicode, Inc.

Each is reproduced under the terms of its own license. The full Unicode
License Version 3 (the license that governs the bundled ICU binaries) is
shipped with this repository as `UNICODE-LICENSE.txt` at the root and is
also packaged inside the produced NuGet under the same name.

   Modifications made during port:
     - The MSBuild target name `AddUnoIcuEmbeddedResource` was renamed to
       `AddCodeBrixPlatformUnicodeEmbeddedResource` (Windows package) and
       `AddCodeBrixPlatformUnicodeMacOsEmbeddedResource` (macOS package)
       in the respective Common.targets files. Target names are
       file-scoped in MSBuild, so these renames are non-breaking changes
       relative to the cross-package guard, and the two CodeBrix names
       are distinct from each other so a consumer importing both packages
       gets no target redefinition.
     - The MSBuild PROPERTY names `$(IsUnoHead)` and `$(UnoIcuDataIncluded)`
       are preserved VERBATIM from upstream Uno.icu-win on purpose: a
       consumer that transitively references both `Uno.icu-win` and
       `CodeBrix.Platform.Unicode` at the same time should still embed
       `icudt.dat` exactly once, not twice. Sharing the
       `$(UnoIcuDataIncluded)` sentinel is what makes that work.
     - csproj packaging metadata (PackageId, Description, Title, Authors,
       PackageProjectUrl, RepositoryUrl, PackageIcon, etc.) all rewritten
       for the CodeBrix.Platform.Unicode product.
     - csproj license expression broadened from `Apache-2.0` (which is
       what upstream Uno.icu's repo LICENSE.md establishes) to
       `Apache-2.0 AND Unicode-3.0` so the Unicode License of the bundled
       ICU 77 native binaries is accurately recorded at the package level.
       Upstream Uno.icu-win 77.2.1's nuspec did not declare any license
       expression at all; this port corrects that by both declaring the
       expression and shipping `UNICODE-LICENSE.txt` to satisfy ICU's
       own Unicode-3.0 redistribution conditions.
     - Standard CodeBrix-family scaffolding added (8 AI-pointer files,
       AGENT-README.txt, README.md, .slnx, InternalsVisibleTo.cs, plus
       a metadata-only managed assembly emitted under net10.0).

2. ICU 77 (International Components for Unicode)
   ----------------------------------------------
   Project URL:    https://icu.unicode.org/
   Source repo:    https://github.com/unicode-org/icu (branch maint/maint-77)
   Copyright:      Copyright (c) 2016-2025 Unicode, Inc.
                   (additional bundled-component copyrights enumerated in
                    UNICODE-LICENSE.txt)
   License:        Unicode License Version 3 (SPDX: Unicode-3.0)

   Files redistributed from this upstream project (binary, bit-for-bit
   identical to the copies that Uno.icu-win 77.2.1 / Uno.icu-macos 77.2.1
   shipped):

     - src/CodeBrix.Platform.Unicode/runtimes/win-x64/native/icuuc77.dll
         (ICU 77 "common" native library — character properties,
          collation, normalization, BiDi, etc. — for Windows x64;
          PE32+ x86-64 DLL, ~2.91 MB)
     - src/CodeBrix.Platform.Unicode/runtimes/win-x64/native/icudt77.dll
         (ICU 77 data shim DLL for Windows x64, ~15 KB)
     - src/CodeBrix.Platform.Unicode/runtimes/win-arm64/native/icuuc77.dll
         (ICU 77 "common" native library for Windows ARM64;
          PE32+ ARM64 DLL, ~2.79 MB)
     - src/CodeBrix.Platform.Unicode/runtimes/win-arm64/native/icudt77.dll
         (ICU 77 data shim DLL for Windows ARM64, ~15 KB)
     - src/CodeBrix.Platform.Unicode/buildTransitive/icudt.dat
         (ICU 77 data archive — the full Unicode/CLDR/timezone data
          tables — ~5.51 MB; embedded as an MSBuild EmbeddedResource
          into Uno-head consumers via the `.targets` files in the same
          folder)
     - src/CodeBrix.Platform.UnicodeMacOs/runtimes/osx/native/libicuuc.dylib
         (ICU 77 "common" native library for macOS; Mach-O universal
          binary, x86_64 + arm64, ~4.06 MB; bit-for-bit identical to the
          copy shipped in Uno.icu-macos 77.2.1)
     - src/CodeBrix.Platform.UnicodeMacOs/runtimes/osx/native/libicudata.dylib
         (ICU 77 data shim library for macOS; Mach-O universal binary,
          ~33 KB; bit-for-bit identical to the copy shipped in
          Uno.icu-macos 77.2.1)
     - src/CodeBrix.Platform.UnicodeMacOs/buildTransitive/icudt.dat
         (second copy of the same ICU 77 data archive, byte-identical to
          the Windows package's copy — verified by checksum during the
          2026-06-12 port)

   No modifications were made to any binary file. The DLLs, dylibs, and the
   data archive are preserved bit-for-bit.

   Version-refresh provenance (2026-06-13): the bundled binaries were
   refreshed from upstream 77.1.2 to 77.2.1. Verified by checksum during the
   refresh:
     - Windows: all four native DLLs (icuuc77.dll + icudt77.dll, x64 and
       arm64) changed between 77.1.2 and 77.2.1 and were replaced.
     - macOS: both dylibs (libicuuc.dylib, libicudata.dylib) are
       byte-identical between 77.1.2 and 77.2.1 — left in place, and the
       statement above (identical to the copies Uno.icu-macos 77.2.1
       shipped) holds true for them under both versions.
     - icudt.dat is byte-identical across both upstream versions and across
       the win/macos packages (single archive, shared by both CodeBrix
       packages).

   The full Unicode License Version 3 text is reproduced in
   `UNICODE-LICENSE.txt` at the root of this repository, and is also
